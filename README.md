# Machine learning para Reconstrução da Estatítica Pesca Brasileira 1950 a 2022
## TED Ministerio da Pesca e Aquicultura e Universidade Federal de Seripe

Projeto de análise e reconstrução de séries temporais de
estatísticas pesqueiras brasileiras entre 1950 e 2022.

## Objetivo

Reconstruir dados históricos da estatistica de desembarque pesqueiro marinho que
apresentam lacunas temporais, utilizando métodos estatísticos
e técnicas de Machine Learning.

## Tecnologias

- Python
- Pandas
- NumPy
- Scikit-learn
- Statsmodels
- PyTorch
- LSTM
- RNN
- ARIMA
- SARIMA
- Matplotlib

## Metodologia

1. Organização dos dados
2. Identificação dos dados faltantes
3. Tratamento das séries temporais
4. Aplicação de métodos estatísticos
5. Aplicação de modelos de Machine Learning
6. Comparação dos resultados
